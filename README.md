Vice City Cover Studio turns any photo and caption into GTA 6-style multi-panel cover art — a Vice City sunset or neon grade, bold lettering, crop and position per panel — and exports it as a PNG in 1080x1080, 1080x1350 or 1920x1080, fully offline in the browser.

## Run it

```sh
node serve.ts
```
